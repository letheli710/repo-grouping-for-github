# Privacy Policy — Repo Grouping for GitHub

*Last updated: November 13, 2026*

**Repo Grouping for GitHub does not collect, transmit, sell or share any personal data.**

## What the extension stores

To show your groups, the extension stores the following **only in your browser's local extension storage** (`chrome.storage.local`) on your computer:

- Group names, colors, order and whether each group is collapsed
- The `owner/repo` names of repositories you put in groups
- Your settings (group style, whether to also show GitHub's original list)

Groups are kept separately for each GitHub account, keyed by the login name shown on the GitHub page.

## What the extension reads

On the GitHub home page (`github.com/`, `/dashboard`, `/feed`), the extension reads the repository links and avatar addresses in the *Top repositories* sidebar list, plus the signed-in login name GitHub includes in the page. It does not read your code, issues, pull requests, cookies, tokens or any other page content.

## What the extension sends

Nothing. The extension has no server, no analytics and no error reporting, and it never sends your data to the developer or any third party. The only network activity it causes is on GitHub itself:

- Displaying the same `avatars.githubusercontent.com` avatar images GitHub already shows in the sidebar
- Clicking GitHub's own *Show more* button in the sidebar to load your full repository list

## Removing your data

Uninstalling the extension removes all of its stored data. You can also delete a group at any time from its **⋯** menu.

## Contact

Questions or concerns: please open an issue at <https://github.com/letheli710/repo-grouping-for-github/issues>.

# 隐私政策 — Repo Grouping for GitHub

*最后更新：2026 年 11 月 13 日*

**Repo Grouping for GitHub 不收集、不传输、不出售、不分享任何个人数据。**

## 保存什么

为了显示分组，扩展**只在你这台电脑的浏览器本地扩展存储**（`chrome.storage.local`）里保存：

- 分组名、颜色、顺序和是否折叠
- 你放进分组的仓库名（`owner/repo`）
- 你的设置（分组样式、是否同时显示 GitHub 原生列表）

分组按 GitHub 账号分开存放，以页面上显示的登录名区分。

## 读取什么

在 GitHub 首页（`github.com/`、`/dashboard`、`/feed`），扩展读取侧边栏「Top repositories」列表里的仓库链接和头像地址，以及 GitHub 页面里写明的当前登录名。不读取你的代码、issue、pull request、cookie、token 或页面上的其他内容。

## 发送什么

什么都不发送。扩展没有服务器、没有统计、没有错误上报，不会把你的数据发给开发者或任何第三方。它引起的网络活动只发生在 GitHub 自己身上：

- 显示侧边栏里 GitHub 本来就在显示的同一批 `avatars.githubusercontent.com` 头像
- 点击侧边栏里 GitHub 自己的「Show more」按钮，加载完整的仓库列表

## 删除数据

卸载扩展会删除它保存的全部数据。你也可以随时在分组的 **⋯** 菜单里删除分组。

## 联系

有任何疑问，请在 <https://github.com/letheli710/repo-grouping-for-github/issues> 提交 issue。
